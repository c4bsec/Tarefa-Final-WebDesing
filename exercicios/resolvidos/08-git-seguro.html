Exercício resolvido 08

Git seguro

Fluxo completo para revisar e publicar mudanças sem colocar credenciais na URL.

Exercícios resolvidos/Git seguro

Resposta resolvida

Use autenticação oficial: Git Credential Manager ou SSH. O endereço remoto não deve conter usuário, senha ou token.

Sequência correta

# 1. Conferir as alterações
git status
git diff

# 2. Preparar e registrar
git add .
git commit -m "Resolve exercícios de Web Design"

# 3. Atualizar e publicar
git pull --rebase origin main
git push origin main
✓

Remoto limpo

Use somente https://github.com/organizacao/projeto.git ou uma URL SSH.

✓

Segredos ignorados

Mantenha .env, chaves e arquivos locais fora do versionamento.

✓

Revisão antes do envio

Confira o diff e procure credenciais antes de publicar.
