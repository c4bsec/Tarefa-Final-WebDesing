Exercício resolvido 09

Front Controller

O caminho completo de uma requisição em uma aplicação com Nginx e PHP-FPM.

Exercícios resolvidos/Front Controller

Resposta resolvida

Fluxo: navegador → Nginx → public/index.php → roteamento e regra de negócio → view → resposta HTTP.

Fluxo da requisição

  1. Navegadorenvia a requisição HTTP
  2. Nginxentrega arquivos ou encaminha ao PHP
  3. Front Controllerpublic/index.php centraliza a entrada
  4. Aplicaçãoroteia, valida e executa regras
  5. Viewgera a resposta HTML

Exemplo simplificado

<?php
require __DIR__ . '/../src/bootstrap.php';

$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);

if ($path === '/') {
    $products = $store->products();
    require __DIR__ . '/../views/home.php';
    exit;
}

http_response_code(404);
