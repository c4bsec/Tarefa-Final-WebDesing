# Atividade 3 - Elementos do HTML5

## Objetivo

Reunir em uma página educacional os principais recursos do HTML5: imagens, vídeo, áudio, formulário, links, listas, tabelas, identificadores, classes e contêineres.

## Duas versões

### `codigo-original/`

Snapshot recuperado do commit `c1bf24b560a12b7517f50b1e876df91e9f6ab811` em:

<https://github.com/rubensbelarmino/Grupo_1_CATIN2_Web_Design>

O HTML e os arquivos vazios de CSS/JavaScript foram preservados. As mídias comerciais presentes no repositório de origem não foram redistribuídas.

### `exemplo-reconstruido/`

Versão didática revisada, responsiva e independente de imagens externas. Inclui formulário acessível, tabela, lista, ilustração SVG e um pequeno áudio sintético criado para a atividade. O vídeo comercial foi substituído por um pôster explicativo, mantendo o elemento `video` como exemplo de marcação.

## Executar

Abra [exemplo-reconstruido/index.html](exemplo-reconstruido/index.html) no navegador. Para testar o formulário e os recursos locais de maneira consistente, use um servidor HTTP local.
