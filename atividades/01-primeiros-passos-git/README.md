# Atividade 1 - Primeiros passos com projeto web e Git

## Objetivo

Criar a estrutura inicial de um projeto web com arquivos separados para marcação, estilo e comportamento, além de registrar o trabalho com Git.

## Situação do código

O relatório referencia o repositório `rubensbelarmino/atividadeeena`, que não estava acessível na recuperação. O conteúdo em `codigo-reconstruido/` foi refeito a partir da descrição e das capturas do relatório. Ele não é apresentado como original.

## Conteúdos praticados

- Estrutura mínima de uma página HTML5.
- Ligação de `style.css` e `script.js` externos.
- Organização de cabeçalho, navegação, conteúdo e rodapé.
- Evento de clique e atualização do DOM.
- Fluxo básico de `git add`, `git commit` e `git push`.
- Autenticação segura sem incluir token na URL.

## Executar

Abra [codigo-reconstruido/index.html](codigo-reconstruido/index.html) no navegador.
