# Atividade 4 - PHP, CSS e infraestrutura

## Objetivo

Estudar a arquitetura de uma aplicação PHP com ponto de entrada único, folha de estilos responsiva e configuração de serviços para produção.

## Conteúdos praticados

- `public/index.php` como Front Controller.
- Inicialização da aplicação em `src/bootstrap.php`.
- Layout compartilhado em `views/layout.php`.
- Design tokens, Grid, Flexbox e media queries em `public/assets/app.css`.
- Nginx, PHP-FPM, OPcache e Docker Compose.
