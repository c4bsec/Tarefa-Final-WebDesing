# Atividade 5 - Projeto final, JavaScript e DOM

## Objetivo

Analisar o projeto Elda Bolos e Doces como aplicação final da disciplina, relacionando HTML renderizado por templates PHP, CSS responsivo, JavaScript externo, documentação e histórico de Git.

## Funcionalidades JavaScript estudadas

1. Menu mobile e atualização de `aria-expanded`.
2. Notificações temporárias.
3. Máscaras de telefone, CEP e CPF.
4. Envio automático de formulário por seleção.
5. Alternância de visibilidade da senha.
6. Cópia de código PIX.
7. Contagem regressiva de autenticação.
8. Consulta periódica de pagamento.
9. Prévia e validação de imagem no cliente.
10. Pré-carregamento de recursos.

Leia primeiro [codigo-original/README.md](codigo-original/README.md). O projeto depende de PHP, banco de dados e configuração de ambiente. Use apenas valores de desenvolvimento e não publique arquivos `.env`.
